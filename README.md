# **📈BONG'S TALK**
```
**AI기반 봉식이의 주식추천 시스템**  

BONSIK + STOCK (봉식과 주식) -> 봉스톡 -> BONG'S TALK 봉식이의 주식 이야기
```
## 프로젝트 배경
```
주식 시장의 정보는 방대하고 변화가 빠르기 때문에, 개인 투자자가 모든 뉴스를 실시간으로 분석하고 대응하기는 어렵습니다.
본 프로젝트는 이러한 한계를 극복하기 위해 머신러닝과 자연어 처리(NLP) 기술을 접목하여,
투자 판단을 보조할 수 있는 자동화된 주식 추천 시스템을 구축하고자 했습니다.
```
## 프로젝트 개요
```
이 프로젝트는 머신러닝 및 감성분석 기법을 활용하여 S&P 500 종목의 주가 상승 가능성을 예측하는 
웹 기반 주식 추천 시스템입니다. 뉴스 기사, 주가 데이터, 감정 점수 등을 종합적으로 분석하여  
추천 순위를 제공합니다.
```
## 🔍 주요 기능
```
•	📊 종목별 상승 확률 예측  
과거 데이터 기반 ML 모델로 종목별 상승 확률 산출  

•	📰 뉴스 기반 감성 분석   
회사 관련 뉴스 기사 본문을 분석하여 감정 점수 생성  

•	📅 날짜별 데이터 검색  
예측일 기준으로 뉴스/예측/검증 데이터 통합 조회  

•	🏢 종목별 상세 검색  
특정 회사의 예측 정보 및 실제 등락 확인 가능  

•	📈 종합 점수 기반 추천 순위 제공  
상승확률과 감정점수를 가중합하여 추천 종목 결정
```

## 데이터 구성
```bash
  - 뉴스데이터 : 뉴스학습을 위한 데이터, 최근 5일간 뉴스를 분석해 -1 ~ 1 범위 점수화.
  - 차트데이터 : 학습을 위한 데이터, 상승 하락 차트 바탕으로 학습
  - 예측데이터 : 최근 28일간 주가 지표를 분석해 0 ~ 100 % 확률화.  
             확률 >= 50 상승 , 확률 < 50 하락
  - 검증데이터 : 예측이 정확도를 확인하기 위한 데이터.  
              5월 30일날 예측을 했다면 검증데이터는 6월 1일자 데이터.  
              5월 30일 실제 상승여부 확인
  - 테스트데이터 : 다음날을 예측하기 위해 당일까지 나온 주가 지표를 바탕으로
               실제 예측에 사용될 데이터. 테스트 데이터를 바탕으로
               예측 데이터가 생성됨.
```
## 사용 기술 스택

| 범주 | 도구/프레임워크 | 설명 |
|------|------------------|------|
| 언어 | Python | 전체 백엔드 및 데이터 분석 |
| 웹 프레임워크 | Flask | 웹 서버 구축 |
| 머신러닝 | XGBoost, Optuna | 주가 예측 및 하이퍼파라미터 튜닝 |
| NLP | HuggingFace Transformers, spaCy | 뉴스 요약, 감정 분석, 개체명 인식 |
| 외부 API | yfinance | 주가 데이터 수집 |

## 모델 학습 방법

  - 사용모델  
    주가 데이터 :  
    | 용도                 | 모델명                   | 프레임워크    | 주요 기능                      |
    |----------------------|-------------------------|--------------|---------------------------|
    |  주가예측  | XGBOOST | xgboost | 주가 데이터 기반 에측, 회귀/분류 |   

    
    뉴스 데이터 :
    | 용도                 | 모델명                   | 프레임워크    | 주요 기능                      |
    |----------------------|-------------------------|--------------|---------------------------|
    | 요약(Summarization)  | facebook/bart-large-cnn | Transformers | 영어 텍스트 요약        |
    | 개체명 인식(NER)     | dslim/bert-base-NER     | Transformers | 영어 엔티티 추출          |
    | 감정 분석            | yiyanghkust/finbert-tone| Transformers | 금융 텍스트 감정 분석      |
    | 일반 NLP 파이프라인  | en_core_web_sm          | spaCy        | 토크나이즈, NER 등         |
  - 학습방법  
    주가 데이터 : 주가지표 칼럼과 타켓 칼럼 (1,0)을 학습 한 후 테스트데이터로 예측을 실행한다.
    
    뉴스 데이터 : 최근 5일간 뉴스를 스크랩 해와서 본문을 요약한다. 개채명 인식 (NER)과 NLP파이프라인으로
               토크나이즈 한다. 간단한 예로는 "APPLE and NVIDIA increase while GOOGLE decrease."
               경우 개체명 인식 "APPLE", "NVIDIA", "GOOGLE" 을 추출하고 문장을 "APPLE and NVIDIA
               increase", "while GOOGLE decrease."로 분리한후 각 개체별 감정분석 진행후
               실제 회사명과 같은 개체만 반영한다

## 모델 학습
```
  - xgboost 사용시 optuna로 하이퍼 파라미터 조정
    주가 예측 모델 accuracy : 0.83 (전체 상승, 하락 예측)
  - 뉴스 데이터 예측 accuracy : 0.96 (상승 예측 시 실제 상승일 확률)

```

## 결과 분석
```
시각화를 위해 뉴스데이터, 차트데이터, 예측데이터, 검증데이터, 테스트데이터로 구분해 저장

날짜별 분석을 위해 종목별  예측 / 상승 여부로 확인
상승 예측 시 실제 상승 확률 확인
기업별 분석을 위해 날짜별 예측 / 상승 여부로 확인
```
## 사용  예시

1. 사용자가 웹에 접속하면, 예측 날짜와 추천 종목 리스트가 표시됩니다.
2. 각 종목을 클릭하면 관련 뉴스, 차트 기반 지표, 감정 점수 등이 함께 표시됩니다.
3. 사용자는 관심 종목을 선택하고, 실제 검증 결과도 함께 확인할 수 있습니다.
4. 또한, 날짜별/종목별 분석 메뉴를 통해 상승 예측 정확도를 추적할 수 있습니다.
